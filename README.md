# TORTEX Gift Hamper Website

Static website ready for GitHub Pages.

## Files
- `index.html` — website
- `style.css` — design
- `script.js` — buttons/menu/WhatsApp
- `logo.png` — TORTEX logo

## Before publishing
Open `index.html` and `script.js` and replace `91XXXXXXXXXX` with your WhatsApp number.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all four files.
3. Go to Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save. Your website will get a GitHub Pages link.
