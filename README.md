# TORTEX Pro Gift Hamper Website

Premium, animated static e-commerce homepage for TORTEX.

### Included
- Premium hero photography and product visuals
- Responsive mobile/desktop design
- Scroll reveal animations
- Hero zoom/parallax-style motion
- Floating badge and marquee animation
- Animated cart drawer
- Add to Cart
- WhatsApp checkout using **9582037458**
- Corporate gifting enquiry
- TORTEX logo included

### GitHub Pages
Upload the complete contents to a GitHub repository.
Go to **Settings → Pages → Deploy from a branch → main → / (root)**.

The site is static HTML/CSS/JS, so no server is required.

### Important
The hamper photography in this starter is used as branded visual artwork. Replace the files inside `assets/` with your actual product photographs whenever you have them; the website layout will automatically use the new images.
